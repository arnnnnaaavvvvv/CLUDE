# Contributing to CLUDE

Thank you for your interest in contributing to **CLUDE**! We welcome code contributions, bug reports, and architectural improvements.

## Development Workflow

1. **Fork or Branch**: Create a feature branch off `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Local Environment**:
   - Backend: Python 3.11+, install dependencies with `pip install -r backend/requirements.txt`
   - Frontend: Node.js 18+, install with `npm install` inside `frontend/`
3. **Commit Standards**:
   - Write clear, imperative commit messages (`feat:`, `fix:`, `docs:`, `test:`).
   - Attribute co-authors using `Co-authored-by:` git trailers when pairing.
4. **Pull Requests**:
   - Open a pull request against `main`.
   - Provide a concise summary of your changes and any test runs.
