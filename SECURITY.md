# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of CLUDE seriously. If you discover a vulnerability or security flaw, please report it responsibly:

1. **Do not create a public issue.**
2. Email details to: `arnav152007@gmail.com` with a summary of the vulnerability, reproduction steps, and potential impact.
3. We will acknowledge receipt within 48 hours and work on a prompt remediation.
